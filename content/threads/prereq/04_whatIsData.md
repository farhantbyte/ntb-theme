**داده (Data)** به هر مقدار، نماد، متن، تصویر، صدا یا مشاهده‌ ای گفته می‌ شه که ثبت یا ذخیره شده باشه، اما به‌ تنهایی لزوماً معنی یا مفهوم خاصی رو منتقل نکنه.

در ترد قبل با **اطلاعات (Information)** آشنا شدیم و گفتیم اطلاعات چیزی است که دانسته‌ های ما را بیشتر می‌ کند یا از ابهام ما کم می‌ کند.

حالا نوبت یکی از مهم‌ ترین واژه‌ های دنیای علم داده است: **داده (Data)**

---
گفتیم:

> **داده (Data)** به هر مقدار، نماد، متن، تصویر، صدا یا مشاهده‌ ای گفته می‌ شه که ثبت یا ذخیره شده باشه، اما به‌ تنهایی لزوماً معنی یا مفهوم خاصی رو منتقل نکنه.

شاید این تعریف در نگاه اول کمی مبهم به نظر برسه🤷🏻‍♂️، پس بیاید با مثال جلو بریم.


{{< readmore type="info" title="مثال اول" open="false" >}}


فرض کن فقط این عدد رو روی کاغذ ببینی:

```
21
```

این چیه؟ نمی‌ دونیم.

ممکنه:
- سن یک نفر باشه.
- دمای هوا باشه.
- نمرهٔ امتحان باشه.
- تعداد کتاب‌ ها باشه.
- قیمت یک محصول باشه.
- شمارهٔ اتوبوس باشه.    

خود عدد **21** فقط یک داده است.

تا زمانی که زمینه (Context) نداشته باشیم، معنی مشخصی نداره.

{{< /readmore >}}

{{< readmore type="info" title="مثال دوم" open="false" >}}


فرض کن فقط این جمله رو ببینی:

```
علی
```

این هم داده است.

اما:

- اسم یک دانشجوست؟   
- اسم یک معلم؟   
- اسم نویسنده؟    
- اسم مشتری؟

هنوز نمی‌ دونیم.

{{< /readmore >}}

{{< readmore type="info" title="مثال سوم" open="false" >}}

این رو ببین:

```
1405/04/26
```

این هم داده است.

ولی:

- تاریخ تولده؟
- تاریخ امتحانه؟  
- تاریخ خرید؟
- تاریخ انتشار کتاب؟ 

باز هم معلوم نیست.

{{< /readmore >}}

{{< readmore type="info" title="مثال چهارم" open="false" >}}

یک عکس از یک گربه. خود عکس یک داده است.
ممکنه بعدها یک برنامهٔ هوش مصنوعی به عکس نگاه کنه و بگه:

> «این یک گربه است.»

اما قبل از این تحلیل، خود عکس فقط مجموعه‌ ای از میلیون‌ها پیکسل ذخیره‌ شده است.

{{< /readmore >}}

{{< readmore type="info" title="مثال پنجم" open="false" >}}

یک فایل صوتی.

خود فایل صوتی داده است.

بعداً شاید یک مدل تشخیص گفتار آن را به متن تبدیل کند.

یا شاید یک انسان آن را گوش دهد.

اما قبل از این تحلیل، فقط داده است.

{{< /readmore >}}

{{< readmore type="info" title="مثال ششم" open="false" >}}

فرض کن ساعت هوشمندت ضربان قلبت رو در پنجره های 1 دقیقه ای ذخیره می‌ کنه

مثلاً:



$$\mathbf{t} = [\ldots, 09{:}58, 09{:}59, 10{:}00, 10{:}01, 10{:}02, 10{:}03, 10{:}04, 10{:}05, 10{:}06, 10{:}07, \ldots]$$
$$\mathbf{x}=[\ldots,71,73,72,75,74,76,78,77,75,74,\ldots]$$

این‌ها داده هستند.

وقتی پزشک به آن‌ها نگاه می‌کند و نتیجه می‌گیرد:

> «ضربان قلب طبیعی است.»

آن نتیجه، اطلاعات است.

{{< /readmore >}}
