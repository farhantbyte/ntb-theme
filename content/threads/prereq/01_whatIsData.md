**داده (Data)** به هر مقدار، نماد، متن، تصویر، صدا یا مشاهده‌ ای گفته می‌ شه که ثبت یا ذخیره شده باشه، اما به‌ تنهایی لزوماً معنی یا مفهوم خاصی رو منتقل نکنه.
{{< readmore type="" title="یکم بیشتر بدونید" open="true" >}}

در فصل قبل با **اطلاعات (Information)** آشنا شدیم و گفتیم اطلاعات چیزی است که دانسته‌ های ما را بیشتر می‌ کند یا از ابهام ما کم می‌ کند.

حالا نوبت یکی از مهم‌ ترین واژه‌ های دنیای علم داده است: **داده (Data)**

---
گفتیم:

> **داده (Data)** به هر مقدار، نماد، متن، تصویر، صدا یا مشاهده‌ ای گفته می‌ شه که ثبت یا ذخیره شده باشه، اما به‌ تنهایی لزوماً معنی یا مفهوم خاصی رو منتقل نکنه.

شاید این تعریف در نگاه اول کمی مبهم به نظر برسه🤷🏻‍♂️، پس بیاید با مثال جلو بریم.

---

# مثال اول

فرض کن فقط این عدد رو روی کاغذ ببینی:

```
21
```

این چیه؟ نمی‌ دونیم.

ممکنه:
- سن یک نفر باشه.
- دمای هوا باشه.
- نمرهٔ امتحان باشه.
- تعداد کتاب‌ ها باشه.
- قیمت یک محصول باشه.
- شمارهٔ اتوبوس باشه.    

خود عدد **21** فقط یک داده است.

تا زمانی که زمینه (Context) نداشته باشیم، معنی مشخصی نداره.

---

# مثال دوم

فرض کن فقط این جمله رو ببینی:

```
علی
```

این هم داده است.

اما:

- اسم یک دانشجوست؟   
- اسم یک معلم؟   
- اسم نویسنده؟    
- اسم مشتری؟

هنوز نمی‌ دونیم.

---

# مثال سوم

این رو ببین:

```
1405/04/26
```

این هم داده است.

ولی:

- تاریخ تولده؟
- تاریخ امتحانه؟  
- تاریخ خرید؟
- تاریخ انتشار کتاب؟ 

باز هم معلوم نیست.

---

# مثال چهارم

یک عکس از یک گربه. خود عکس یک داده است.
ممکنه بعدها یک برنامهٔ هوش مصنوعی به عکس نگاه کنه و بگه:

> «این یک گربه است.»

اما قبل از این تحلیل، خود عکس فقط مجموعه‌ ای از میلیون‌ها پیکسل ذخیره‌ شده است.

---

# مثال پنجم

یک فایل صوتی.

خود فایل صوتی داده است.

بعداً شاید یک مدل تشخیص گفتار آن را به متن تبدیل کند.

یا شاید یک انسان آن را گوش دهد.

اما قبل از این تحلیل، فقط داده است.

---

# مثال ششم

فرض کن ساعت هوشمندت ضربان قلبت رو در پنجره های 1 دقیقه ای ذخیره می‌ کنه

مثلاً:



$$\mathbf{t} = [\ldots, 09{:}58, 09{:}59, 10{:}00, 10{:}01, 10{:}02, 10{:}03, 10{:}04, 10{:}05, 10{:}06, 10{:}07, \ldots]$$
$$\mathbf{x}=[\ldots,71,73,72,75,74,76,78,77,75,74,\ldots]$$

این‌ها داده هستند.

وقتی پزشک به آن‌ها نگاه می‌کند و نتیجه می‌گیرد:

> «ضربان قلب طبیعی است.»

آن نتیجه، اطلاعات است.

---

# داده همیشه عدد نیست

یکی از رایج‌ ترین اشتباه‌ ها این است که فکر کنیم داده فقط عدد است.

نه.

داده می‌تواند تقریباً هر چیزی باشد.

مثلاً:
- عدد
- متن
- حرف
- کلمه
- جمله
- تصویر
- فیلم
- فایل صوتی
- ایموجی 😀
- مختصات GPS
- دمای هوا
- رنگ
- فایل PDF
- فایل Word
- پیامک
- ایمیل
- لاگ‌های یک سرور
- سیگنال یک حسگر

همهٔ این‌ها داده هستند.
- فقط یک نکته وجود داره که خیلی مهمه: برای اینکه بشه توی کامپیوتر ذخیره و پردازش بشن باید یه راهی وجود داشته باشه که تبدیل به عدد بشن!!

---

# داده خام (Raw Data)

خیلی وقت‌ها دربارهٔ «دادهٔ خام» صحبت می‌ کنیم.

دادهٔ خام یعنی داده‌ ای که هنوز پردازش نشده است.

مثلاً فروش یک فروشگاه:

```md
Ali
Sara
Ali
Ali
Reza
Sara
Ali
```

فقط یک لیست از اسم‌ هاست.

اما اگر بعداً بشماریم که هر نفر چند بار خرید کرده،

دیگه داریم روی داده پردازش انجام می‌دیم.

---

# چرا بهش می‌ گن خام؟

فرض کن سیب از درخت چیده شده.

هنوز:

- پوست نگرفته
- خرد نشده    
- آب‌ گیری نشده
- پخته نشده    

بهش می‌گیم سیب خام.
داده هم همینطوره.
قبل از اینکه مرتب بشه، تحلیل بشه یا معنی ازش استخراج کنیم، بهش می‌ گیم دادهٔ خام.

---

# داده بدون زمینه

به این عدد نگاه کن:

```
38.7
```

چیه؟ نمی‌ دونیم!

اما اگر بگیم:

> دمای بدن بیمار = 38.7 درجه

حالا معنی پیدا می‌ کنه.

یعنی زمینه باعث می‌ شود داده قابل تفسیر شود.

---

# آیا هر چیزی که ذخیره شود، داده است؟

تقریباً بله. اگر بتوان چیزی را ثبت، ذخیره یا منتقل کرد، معمولاً می‌توان آن را داده در نظر گرفت.

برای مثال:

- دوربین امنیتی فیلم ذخیره می‌ کند.
- گوشی عکس ذخیره می‌ کند.
- بانک تراکنش ذخیره می‌ کند.
- اینستاگرام لایک ذخیره می‌ کند.
- مرورگر تاریخچه ذخیره می‌ کند.
- GPS موقعیت ذخیره می‌ کند.
    

همهٔ این‌ها داده تولید می‌ کنند.

---

به این‌ها نگاه کن:

```
25
```

```

```

```
😀
```

```

```

```
https://example.com
```

```

```

همه داده هستند.

اما نوعشون فرق می‌ کنه.

بعداً یاد می‌ گیریم که داده‌ ها انواع مختلفی دارند؛ مثل داده‌ های عددی، متنی، تصویری، صوتی و...

---

# داده به‌ تنهایی همیشه مفید نیست

فرض کن یک هارد پیدا کردی که داخلش ده میلیون عدد وجود دارد.

آیا این یعنی ده میلیون اطلاعات داری؟ نه!

شاید حتی ندونی این عددها مربوط به چه چیزی هستند.

ممکنه اینا:

- دمای هوا باشند.
- قیمت سهام باشند.
- نمرات دانش‌ آموزان باشند.
- یا فقط اعداد تصادفی باشند.

تا زمانی که نفهمیم این داده‌ ها چه هستند و چه معنایی دارند، استفاده از آن‌ ها سخت است.

---

# داده از کجا میان؟!

داده می‌ تواند از جاهای مختلف جمع‌ آوری شود.

مثلاً:

- انسان‌ ها
- پرسشنامه‌ ها
- حسگر ها
- دوربین‌ ها
- میکروفون‌ ها
- ماهواره‌ ها
- موبایل‌ ها
- وب‌سایت‌ ها
- شبکه‌ های اجتماعی
- دستگاه‌ های پزشکی
- خودروها
- بازی‌ های کامپیوتری

تقریباً هر چیزی که بتواند چیزی را ثبت کند، داده تولید می‌ کند.

---

# در علم داده چه اتفاقی میوفته؟

دانشمندان داده معمولاً با خود داده کاری ندارند. هدف آن‌ ها این است که از **داده**، **اطلاعات** استخراج کنند.

داده ← اطلاعات!!!

فرض کن یک فروشگاه این داده‌ ها را دارد:

| نام کالا | تعداد فروش |
| -------- | ---------: |
| شیر      |        ۲۵۰ |
| نان      |        ۴۰۰ |
| پنیر     |        ۱۲۰ |

خود جدول داده است.

اما وقتی مدیر فروشگاه می‌ گه:

> «نان پرفروش‌ ترین محصول ماست.»

این یک اطلاعات است که از روی داده‌ها به دست آمده است.

---

# یک مثال از زندگی روزمره

فرض کن استاد اسامی حاضرین کلاس را نوشته است.

```
علی
سارا
رضا
محمد
```

این فقط داده است.

بعداً مدیر مدرسه بررسی می‌ کند و می‌ گوید:

> «امروز همهٔ دانش‌ آموزان حاضر بودند.»

این نتیجه، اطلاعات است.

---

# یک مثال از هوش مصنوعی

فرض کن می‌ خواهیم مدلی بسازیم که سگ و گربه را تشخیص دهد.

برای آموزش مدل، هزاران عکس جمع‌ آوری می‌ کنیم، به هرکدومش یه **لیبل** (برچسب) میزنیم که بگیم "این عکس سگه"، "اینم عکس سگه"، "این عکس گربس"، "اینم باز عکس سگه" و...

تمام این عکس‌ ها با لیبل هاشون **داده** هستن.

بعد از آموزش، به مذل یه عکس بدیم، میتونه بهمون بگه:

> «این تصویر یک گربه است.»

این خروجی، اطلاعات است.

---

# آیا داده همیشه ارزشمند است؟

نه.

ممکن است میلیون‌ ها داده داشته باشیم که هیچ کاربردی نداشته باشند.

در مقابل، گاهی فقط چند دادهٔ ساده می‌ توانند اطلاعات بسیار مهمی تولید کنند.

پس ارزش داده به این نیست که زیاد باشد؛ به این است که بتوان از آن چیز مفیدی استخراج کرد.

---

# تفاوت داده و اطلاعات (نگاه اولیه)

برای اینکه تفاوت این دو را بهتر حس کنیم، به مثال زیر دقت کن.

روی میز این برگه قرار دارد:

```
محمد
21
تهران
```

این فقط چند داده است.

اما اگر بگوییم:

> «محمد ۲۱ سال دارد و در تهران زندگی می‌کند.»

حالا داده‌ها کنار هم قرار گرفته‌ اند و یک پیام قابل فهم ساخته‌ اند.

یعنی اطلاعات تولید شده است.
